# blastp-homology-search-protein
# nombre del script: blastp_DBuniprot.sh
## Script para descargar ACC proteínas de UniProt y buscar homólogos con blastp remoto (NCBI nr)
## Requisitos: curl, BLAST+ (blastp), gawk y conexión a internet
1. Tener un listado de los accesiones de UniProt
2. Insertar este listado en Lista=(___________), cada accesión separada con espacio, no con comas ni punto y comas, ej: Lista=(P0CW77 Q9SUM5 O65570)
3. Ejecutar en el terminal con bash blastp_NCBI.sh
